# 👁️💀 Projeto Jujutsu Kaisen

Projeto desenvolvido com o objetivo de criar uma página web temática inspirada no universo de **Jujutsu Kaisen**, apresentando informações sobre a obra, seus personagens e suas principais aberturas.

A página foi construída buscando unir **design temático, organização de conteúdo e experiência de navegação**, criando uma interface visualmente relacionada ao universo do anime e permitindo que o usuário explore diferentes seções através do menu de navegação.

## 🎯 Objetivo

O principal objetivo do projeto foi desenvolver uma página temática utilizando conceitos de desenvolvimento Front-End, colocando em prática conhecimentos de estruturação de páginas, estilização, organização de conteúdo e criação de uma experiência de navegação intuitiva.

Além de apresentar informações sobre Jujutsu Kaisen, o projeto também serviu como exercício prático para aprimorar minhas habilidades no desenvolvimento de interfaces web.

## 📚 Sobre o Projeto

A página apresenta uma seção introdutória sobre **Jujutsu Kaisen**, explicando o conceito da obra e sua história, incluindo a jornada de **Yuji Itadori** após entrar em contato com Ryomen Sukuna e o universo das Maldições e dos Feiticeiros.


## 🧭 Navegação

A interface possui um menu de navegação organizado em diferentes áreas:

* 🏠 **Início**
* 📖 **Sobre**
* 👥 **Personagens**
* 🎵 **Aberturas**

Essa organização facilita o acesso às principais informações disponibilizadas no projeto.

## 💻 Desenvolvimento

Durante a criação do projeto, foram colocados em prática conceitos importantes de desenvolvimento Front-End, como:

* Estruturação de páginas web;
* Organização semântica do conteúdo;
* Criação de menus e navegação;
* Organização de informações em diferentes seções;
* Utilização de imagens para representar personagens;
* Desenvolvimento de uma identidade visual temática;
* Estruturação de conteúdo multimídia;
* Construção de uma interface voltada para experiência do usuário.
